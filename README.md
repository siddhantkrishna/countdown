# T− Countdown

A minimal countdown timer inspired by mission-control interfaces.

## Features

- Live countdown
- Pause and resume
- Reset
- Keyboard controls
- Responsive interface
- Minimal black-and-white design
- Inter typography

## Controls

- `SPACE` — Pause / Resume
- `R` — Reset

## Tech Stack

- React
- TypeScript
- Vite
- CSS

## Development

```bash
npm install
npm run dev
