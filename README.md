# T− Countdown

A minimal countdown timer for anything worth counting down to.

## Features

- Countdown to a specific date and time
- Custom event names
- Pause and resume
- Reset
- Shareable countdown URLs
- Fullscreen mode
- Keyboard controls
- Local persistence
- Responsive interface
- Minimal black-and-white design

## Keyboard Controls

| Key | Action |
| --- | --- |
| `SPACE` | Pause / Resume |
| `R` | Reset |
| `S` | Open setup |
| `F` | Fullscreen |
| `ESC` | Close setup |

- React

- Vite
- CSS
